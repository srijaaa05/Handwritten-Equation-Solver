## 📌 Overview

Handwritten Equation Solver is an intelligent machine learning application that converts handwritten mathematical expressions into digital form and computes the final solution automatically. The project combines image processing, character recognition, deep learning, and symbolic mathematics to create a seamless equation-solving experience.

The system captures or uploads an image containing a handwritten equation, identifies individual mathematical symbols, reconstructs the expression, and computes the result using symbolic computation techniques.

## 🚀 Features

* Handwritten digit and symbol recognition
